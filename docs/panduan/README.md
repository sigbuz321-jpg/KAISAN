# Panduan untuk KAISAN Bimbel

Folder ini berisi panduan penggunaan aplikasi dalam Bahasa Indonesia,
ditujukan untuk guru dan admin — bukan untuk developer.

Aturan penulisan:
- Kalimat pendek, satu instruksi per baris
- Sebut nama tombol persis seperti di layar
- Sertakan screenshot
- Jangan pernah menyuruh pembaca membuka terminal
- Akhiri setiap panduan dengan bagian "Kalau terjadi masalah"

Panduan dibuat di modul M7 (serah terima). Daftar file yang harus ada tercantum
di `.claude/commands/handover.md`.
