Tahap 3 — Empat Layar Prioritas

Mobile-first 390 px, max konten max-w-3xl. Semua teks Bahasa Indonesia final. Komponen visual mengikuti token & kelas dari Tahap 1 & 2.

Daftar layar
  1. Daftar latihan /latihan — 3 kondisi
  2. Latihan adaptif /latihan/{subject} — 6 kondisi
  3. Pengerjaan ujian /ujian/{exam} — 6 kondisi
  4. Peringkat /peringkat — 5 kondisi
Catatan tentang desktop. Brief meminta mobile-first; tiap layar ditampilkan penuh pada 390 px. Penyesuaian desktop mengikuti pola container-3xl.desktop (lebar 56 rem, padding 24 px) dan menjaga max konten murid.
Kontrak yang tidak boleh dilanggar (dari brief §2 & §6):
  • Tidak menampilkan angka Elo / tingkat kesulitan ke murid.
  • Kunci jawaban tidak terlihat selama ujian berlangsung.
  • Latihan tidak menambah poin peringkat — harus tampak di UI.
  • Tidak ada notifikasi bernada menyalahkan / hitung mundur memaksa.
  • Touch target minimal 44×44 px, kontras WCAG AA, color-blind (warna + teks + bentuk).

  • Token: --accent-soft untuk glyph mapel, --surface-muted untuk glyph mapel tanpa soal. Card mapel aktif pakai bg-surface + border-border.
  • Blade components: <x-ui.subject-card> (props glyph, title, meta, tone untuk kondisi 'kosong'), <x-ui.tab-bar> dengan active prop, <x-ui.empty> dengan slot.
  • Livewire: App\Livewire\Latihan\Index. Query: Subject::whereHas('questions')->with(['studentLevel' => fn($q) => $q->where('student_id', auth()->id())])->get(). Counter "X soal pekan ini" dari PracticeLog::where('student_id', auth()->id())->where('created_at', '>', now()->subWeek())->count() per mapel.

  • Mapel tanpa soal: card visually disabled (opacity 0.7), tetap tap-able untuk menampilkan alasan "tanyakan ke guru". Arahkan ke kontak guru bila ada.

Catatan implementasi — Latihan adaptif

  • Token: opsi benar/salah pakai kelas .opt.correct / .opt.wrong dari Tahap 2 (sudah mengikat 3 saluran: warna + teks ::after "Benar/Salah" + letter terisi vs berongga).
  • Blade components: <x-ui.question-card>, <x-ui.option label="A" :selected :locked />, <x-ui.feedback tone="success|danger">, <x-ui.save-pill>, <x-ui.level-band />.
  • Livewire: App\Livewire\Latihan\Show. State: $question, $selected, $submitted, $session (counter benar/salah), $sessionDone. Method submit() merekam PracticeLog, menghitung rating delta (tidak ditampilkan), memilih soal berikutnya via algoritma adaptif sederhana (acak dalam band level ±1).
  • Naik level: dipicu ketika akurasi kumulatif dalam band level ≥ 75% dan minimal 10 soal dijawab. Transisi hanya di halaman selesai — tidak ada pop-up tiba-tiba.
  • Sesi selesai: tampilkan ringkasan dengan nada tenang, tanpa ajakan "Lanjut lagi!". Tombol utama adalah Selesai, bukan "Mulai sesi baru" — penutup yang memuaskan, bukan yang memancing.
  • Save pill: update setiap 8 detik via wire:poll, transisi halus 200 ms. Tidak ada animasi pulse untuk menghemat CPU.
  • Kontrak penting: kalimat "Latihan tidak menambah poin peringkat" muncul di (a) halaman indeks, (b) halaman selesai, dan (c) setelah setiap jawaban salah. Tiga titik untuk memastikan murid paham.

Catatan implementasi — Pengerjaan ujian

  • Token: .timer.urgent di --danger-soft+--danger-text (kontras 4.5:1). Q-map pakai .qmap-cell.answered (--accent-soft) dan .active (--accent solid) — tiga state tanpa emoji.
  • Kunci jawaban TIDAK terlihat: tidak ada kelas .correct/.wrong yang di-hydrate dari backend sampai status ujian = selesai. Backend ExamAttemptController@show strip field correct_option_id dari payload selama attempt in-progress.
  • Blade components: <x-ui.exam-header> (timer + save-pill + counter), <x-ui.qmap :attempt :size=20>, <x-ui.option locked />.
  • Livewire: App\Livewire\Ujian\Kerjakan. State: $attempt, $currentQuestion, $answers[], $secondsLeft. Method saveAnswer() debounce 800 ms lalu PATCH /api/attempts/{id}/answers — payload ringan (cuma question_id + option_id).
  • Auto-save: setiap 8 detik wire:poll.8s ping endpoint /api/attempts/{id}/heartbeat. Backend mengembalikan timestamp yang ditampilkan di .save-pill. Indikator .saving aktif selama request in-flight. Tidak ada blocking UI.
  • Timer: dihitung server-side dari ends_at (UTC). Livewire re-render setiap 1 detik via wire:poll.1s. State .urgent aktif saat $secondsLeft <= 60. Tidak pernah jadi 0:00 tanpa submit — backend auto-submit pada ends_at.
  • Konfirmasi kumpulkan: menampilkan jumlah soal kosong dengan nada netral ("5 soal belum dijawab"), bukan menyalahkan ("Kamu belum jawab 5 soal!"). Tombol utama Ya, kumpulkan, sekunder Kembali mengerjakan.
  • Error states: ujian ditutup dan waktu habis menggunakan pesan yang sama — alasannya sama (window waktu tertutup). Tone netral, menyuruh murid menghubungi guru kalau merasa keliru.
  • Performa: tidak ada CSS animation di halaman ini selain transisi timer. Q-map di-render server-side sebagai HTML statis (tidak via JSX) untuk menghindari reflow 150 kartu pada viewport. Cache attempt di Redis selama ujian berlangsung untuk response < 100 ms.
  • Concurrency: ketika 150 murid submit bersamaan, endpoint /api/attempts/{id}/submit masuk queue exam-grading; UI menampilkan "Menunggu penilaian" tanpa angka nilai sampai guru selesai menilai.

Catatan implementasi — Peringkat

  • Token: peringkat 1 pakai --accent, 2-3 pakai --rank-2/--rank-3 dari Tahap 1. Baris sendiri (.lb-row.you) di---accent-soft + border --accent. Tidak ada warna khusus untuk "di luar 20 besar" — itu ditampilkan dalam card terpisah .lb-you-outside.
  • Blade components: <x-ui.season-card>, <x-ui.lb-row :rank :name :meta :pts :isYou>, <x-ui.lb-self-outside :rank :points :tests />.
  • Livewire: App\Livewire\Peringkat\Show. Computed $top20: Leaderboard::where('season_id', $activeSeason->id)->orderByDesc('points')->limit(20)->get(). $myRank: position via window function ROW_NUMBER() OVER (ORDER BY points DESC) atau query ringan via where('points', '>', $me->points)->count() + 1 (cukup untuk 500 murid).
  • Filter mapel: pill toggle di-mount dengan Alpine x-data, default "Gabungan". On change, Livewire reload $top20 dengan scope per-mapel. Tidak ada loading skeleton — render server-side, max 50 ms.
  • Off-season: tampilkan musim lampau terakhir (sesuai brief §5 — tidak dihapus saat reset). Pesan tenang, menyuruh murid melanjutkan latihan/ujian biasa tanpa membuat merasa dirugikan.
  • Belum ada poin: CTA-nya adalah "Lihat ujian yang tersedia", bukan "Mulai sekarang!" — penutup yang tenang, sesuai arah rasa brief.
  • Tanpa angka Elo: hanya poin terlihat, tidak ada rating. Badge level tetap memakai token dari Tahap 2 (Pemula/Berkembang/Mahir/Ahli).
  • Tone tenang pada kekalahan: baris di luar 20 besar tidak menampilkan "kamu tertinggal dari teman-temanmu" atau pesan motivasional yang menghakimi. Hanya fakta: peringkat, poin, jumlah ujian selesai.
Ringkasan Tahap 3. 4 layar × 20 kondisi visual (3 + 6 + 6 + 5). Setiap layar menampilkan mobile 390 px sebagai fokus utama. Catatan implementasi mencakup token Tailwind v4 yang dipakai, nama Blade component, logika Livewire, dan strategi performa untuk beban 150 murid bersamaan. Kontrak brief §2 & §6 diverifikasi per-layar: tidak ada Elo, tidak ada kunci jawaban di ujian, kontrak "latihan tidak menambah poin" muncul di 4 layar relevan, color-blind (warna + teks + bentuk) konsisten di seluruh opsi jawaban, touch target ≥ 44 px di semua kontrol interaktif.
