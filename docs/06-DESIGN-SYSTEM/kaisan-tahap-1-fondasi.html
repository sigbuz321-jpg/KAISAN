KAISAN · Design System

Tahap 1 — Fondasi

Palet · Tipografi · Jarak · Radius · Shadow
Mobile-first 390 px · Sistem stack · Tanpa CDN

Token di bawah ini adalah sumber satu-satunya untuk halaman murid dan panel guru. Tempelkan blok @theme { } ke resources/css/app.css, lalu hapus token lama. Setelah dipasang, Tailwind v4 otomatis mengenali kelas seperti bg-accent, text-success, dan rounded-lg.

Konflik 1 · Palet murid vs Filament

Satu warna primer: amber hangat

Murid dan guru pakai palet yang sama. Filament 4 dipaksa memakai Color::hex('#D97706') untuk primary (override default Color::Amber agar hue-nya seragam), lalu di PanelProvider daftarkan FilamentColor::register(['primary' => Color::hex('#D97706')]).

Konflik 2 · Font hantu

Hapus 'Instrument Sans', pakai system stack

Murid pakai Android/iOS kelas menengah, RAM 4 GB, 4G lambat, 150 orang bersamaan saat ujian. Memuat font web menambah ~50–100 KB per halaman dan blocking render — risiko nyata di beban puncak. System stack (San Francisco di iOS, Roboto di Android) sudah dioptimasi vendor dan gratis. --font-sans di bawah menimpa nilai default Tailwind agar tidak ada fallback ke 'Instrument Sans' yang tak pernah dimuat.

Bayangan

Tetap datar, 1 pengecualian

90% komponen tanpa shadow. Kartu soal aktif dan bottom-sheet modal boleh shadow-elevated / shadow-modal sebagai cue kedalaman. Tanpa shadow berarti render lebih murah di kelas menengah.

Animasi

Transisi warna & opacity saja

transition-colors duration-150 untuk state (benar/salah, hover). transition-opacity untuk banner. Bar progres pindah value, bukan layout. Tanpa keyframes, tanpa parallax, tanpa auto-play.

Ikon

Heroicons outline, SVG inline

Pakai Heroicons (24/24, outline, 1.5 px stroke) sebagai markup <svg> langsung di Blade component. Tidak ada library JS, tidak ada CDN, tidak ada permintaan jaringan tambahan. Filament sudah menyertakan Blade Icons + Heroicons, jadi guru & murid berbagi set yang sama.

Blok @theme siap tempel

resources/css/app.css

Ganti seluruh isi resources/css/app.css dengan blok di bawah. Tailwind v4 akan otomatis mendaftarkan semua warna dan font sebagai utility.

  --color-muted:           oklch(0.55 0.01 250);     /* teks sekunder, label */

Skala tipografi

System stack untuk semua peran. Display memakai weight 600, body 400, UI/label 510. Huruf besar wajib tracking-[0.06em] atau lebih.

display Latihan adaptif
h1 · 28 Pilih mata pelajaran
h2 · 22 Sesi latihan kamu
h3 · 18 Soal latihan · Matematika
body · 16 Hitunglah nilai dari 12 × (3 + 5). Tuliskan langkah penyelesaian sebelum menulis jawaban akhir.
small · 14 Terakhir berlatih 2 hari lalu. Akurasi 78%.
caps · 12 Label kategori

Benar

Display/H1 (≥28px): letter-spacing: -0.015em sampai -0.02em. Body: 0. ALL CAPS: 0.06em–0.1em.

Salah

Huruf besar tanpa tracking (mis. LEVEL), display longgar (mis. Latihan), dan body justified adalah tiga kegagalan AI yang paling mudah terlihat.

Aturan ikon & animasi

Ikon — Heroicons outline, SVG inline

Pakai hanya ikon 24/24 outline, stroke 1.5 px, warna currentColor.

Lokasi file: resources/views/components/icon/{name}.blade.php (Blade component menerima name + class, render markup <svg> lengkap). Tidak ada JS, tidak ada CDN.

Animasi — minimum

Tiga kelas saja yang dipakai. Tidak ada keyframes, tidak ada spring, tidak ada auto-play.

  • transition-colors duration-150 · hover tombol, perubahan status benar/salah.
  • transition-opacity duration-200 · banner simpan otomatis, banner pesan.
  • transition-transform duration-150 · tekan tombol (2 px ke bawah).

Bar progres pindah value (lebar) dengan transition-[width] duration-300 ease-out — satu-satunya transisi value di aplikasi.

Catatan implementasi

Setelah menempel @theme

  1. Jalankan npm run build (atau vite build) sekali untuk meregenerasi utilitas.
  2. Cari penggunaan warna hardcoded lama (mis. bg-slate-900, text-amber-600) dan ganti ke bg-fg, text-accent-text.
  3. Konfirmasi tidak ada lagi tailwind.config.js — semua konfigurasi via @theme.

Filament 4 — samakan primary

Override Color::Amber default dengan hex yang sama: 

// app/Providers/Filament/AdminPanelProvider.php
use Filament\Support\Colors\Color;
use Filament\Support\Facades\FilamentColor;

FilamentColor::register([
  'primary' => Color::hex('#D97706'),
]);

Setelah override ini, tombol, fokus ring, dan active state panel guru memakai amber yang sama dengan halaman murid — tidak ada dua identitas visual lagi.

Komponen Blade yang akan datang

Tahap 2 akan menambah Blade component bersama di resources/views/components/ui/: button, badge, card, progress, banner, input, tab, leaderboard-row, answer-option, dan question-card. Token di sini dipakai oleh semuanya.

Hal yang TIDAK dipakai di Tahap 1

  • Dark mode (diputuskan: tidak dibuat).
  • Font eksternal, ikon library JS, gradient dekoratif.
  • Bayangan pada kartu standar dan tombol.
  • Stroke lebih tebal dari 1 px pada border.
