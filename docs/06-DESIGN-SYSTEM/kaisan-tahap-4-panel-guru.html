Tahap 4 · Penyelarasan Panel Guru

Filament dipakai apa adanya — hanya palet, navigasi, dan satu widget dasbor yang disentuh.

Panel guru tidak didesain ulang. Bentuk komponen Filament 4 tetap; kustomisasi berhenti di warna primer, ikon dan urutan menu, serta satu Blade view untuk widget dasbor. Hasilnya panel guru terasa satu keluarga dengan halaman murid, tanpa menulis ulang package.

Mengikuti Tahap 1–3 · Token konsisten · Tanpa ubah bentuk Filament

A · Palet

Satu warna primer untuk murid dan guru

Konflik dari Tahap 1 (halaman murid slate/hitam, Filament Color::Amber) diselesaikan dengan override di Panel Provider. primary mengarah ke hex yang sama dengan token --accent murid; gray diarahkan ke Slate agar komponen netral Filament tidak lagi abu-abu hangat yang berbeda.

Catatan Filament 4. Di versi ini, palet di-deklarasikan lewat Filament\Support\Colors\Color. Hex ditulis sebagai string di constructor, atau pakai helper Color::hex(...). Hindari Color::Amber default — itu amber-500 (#F59E0B), satu tingkat lebih cerah dari token murid dan akan terlihat sebagai dua warna berbeda saat halaman murid dan panel guru ditampilkan bersebelahan.

Cara menempel di panel provider

// app/Providers/Filament/GuruPanelProvider.php
use Filament\Support\Colors\Color;
use Filament\Panel;
use Filament\PanelProvider;

class GuruPanelProvider extends PanelProvider
{
    public function panel(Panel $panel): Panel
    {
        return $panel
            ->default()
            ->id('guru')
            ->path('guru')
            ->login()
            ->brandName('KAISAN · Guru')
            ->colors([
                // sinkron dengan --accent murid
                'primary' => Color::hex('#D97706'),
                // gray slate menggantikan default abu-abu hangat
                'gray'    => Color::Slate,
                // 4 semantic disinkronkan dengan token murid
                'success' => Color::hex('#15803D'),
                'warning' => Color::hex('#B45309'),
                'danger'  => Color::hex('#B91C1C'),
                'info'    => Color::hex('#1D4ED8'),
            ])
            ->viteTheme('resources/css/filament/guru.css')
            ->discoverResources(in: app_path('Filament/Guru/Resources'))
            ->discoverPages(in: app_path('Filament/Guru/Pages'))
            ->discoverWidgets(in: app_path('Filament/Guru/Widgets'))
            ->widgets([
                \App\Filament\Guru\Widgets\GuruOverview::class,
            ]);
    }
}
Jangan ubah shape komponen. Brief §2 tegas: bentuk komponen Filament 4 tidak diubah. Override di atas terbatas pada colors, brandName, viteTheme path, daftar resource & widget. Tidak ada renderHook yang memodifikasi struktur komponen, tidak ada Blade view bawaan Filament yang di-patch.

Cara menempel di Filament

// app/Filament/Guru/Widgets/GuruOverview.php
namespace App\Filament\Guru\Widgets;

use App\Models\Question;
use App\Models\Exam;
use Filament\Widgets\Widget;
use Illuminate\Support\Carbon;

class GuruOverview extends Widget
{
    // lebar penuh di grid dasbor Filament
    protected int | string | array $columnSpan = 'full';

    // view kustom — bukan StatsOverviewWidget default
    protected static string $view = 'filament.guru.widgets.guru-overview';

    public function getAntrianCount(): int
    {
        // soal yang butuh tinjauan: status = pending_review
        return Question::where('status', 'pending_review')->count();
    }

    public function getAntrianBaruMingguIni(): int
    {
        return Question::where('status', 'pending_review')
            ->where('created_at', '>=', Carbon::now()->subWeek())
            ->count();
    }

    public function getUjianAkanDatang(): int
    {
        return Exam::where('starts_at', '>', Carbon::now())->count();
    }

    public function getUjianBerikutnya(): ?Exam
    {
        return Exam::where('starts_at', '>', Carbon::now())
            ->orderBy('starts_at')
            ->first();
    }

    public function getBiayaAiBulanIni(): float
    {
        // total cost dari kolom cost_cents (lihat catatan Opsional di Section D)
        $cents = Question::where('is_ai_generated', true)
            ->whereBetween('created_at', [
                Carbon::now()->startOfMonth(),
                Carbon::now()->endOfMonth(),
            ])
            ->sum('cost_cents');

        return $cents / 100;
    }

    public function getBatasBiayaAi(): float
    {
        return (float) config('ai.monthly_budget_idr', 100000);
    }

    public function getAntrianList(): \Illuminate\Database\Eloquent\Collection
    {
        return Question::with('subject')
            ->where('status', 'pending_review')
            ->latest()
            ->limit(5)
            ->get();
    }
}

D · Catatan implementasi

Yang perlu dibuat, apa yang sudah ada, dan satu hal opsional

Daftar file yang harus dibuat di repo, urutan eksekusi yang aman, dan satu kolom yang belum ada di schema tapi dipakai widget.

Berkas yang dibuat

  • app/Providers/Filament/GuruPanelProvider.php Override colors() dengan Color::hex('#D97706') + 4 semantic + Color::Slate. Daftarkan GuruOverview::class di widgets().
  • app/Filament/Guru/Widgets/GuruOverview.php Class widget dengan 7 getter: antrianCount, antrianBaruMingguIni, ujianAkanDatang, ujianBerikutnya, biayaAiBulanIni, batasBiayaAi, antrianList.
  • resources/views/filament/guru/widgets/guru-overview.blade.php Grid 3 kolom (stat cards) + 1 kartu antrian. Pakai x-filament::card + x-heroicon-m-*. Jangan patch view bawaan Filament lain.
  • resources/css/filament/guru.css CSS entry untuk panel guru via viteTheme('resources/css/filament/guru.css'). Boleh kosong jika tidak ada kustom — hanya untuk mengaktifkan tema Vite.
  • app/Filament/Guru/Resources/{Question,Exam,Grade,Student}Resource.php Set $navigationGroup, $navigationSort, $navigationIcon, dan getNavigationBadge() untuk QuestionResource.
  • app/Filament/Guru/Pages/Settings.php Halaman Pengaturan sebagai Filament\Pages\Page, group "Akun", sort 6. Konten bisa berupa form ganti password + preferensi notifikasi — di luar scope design system.
  • config/ai.php Satu key: 'monthly_budget_idr' => 100000. Dipakai widget sebagai batas biaya AI.

Hal yang tidak boleh dilanggar

  • Bentuk komponen Filament 4 tetap. Tidak ada renderHook untuk membungkus komponen, tidak ada view override di resources/views/vendor/filament/, tidak ada CSS yang menyasar class internal Filament (prefix fi-).
  • Token murid dipakai ulang, tidak dideklarasi ulang. Hex #D97706 di sini = hex --accent di Tahap 1. Kalau ada perubahan di satu tempat, ubah dua tempat bersamaan (idealnya pin ke config('design.colors.primary')).
  • Tanpa ikon custom atau library ikon ketiga. Heroicons (mit) sudah termasuk dalam Filament 4. Tidak perlu import Blade Icons atau CDN eksternal.
  • Tanpa query langsung dari Resource untuk badge. QuestionResource::getNavigationBadge() delegate ke widget, supaya query dijadwalkan sekali per request.

Urutan eksekusi

  1. Set config('design.colors.primary') di Tahap 1 ke #D97706 jika belum, lalu tarik ke Color::hex(config('design.colors.primary')) di Provider agar satu sumber.
  2. Generate Filament panel: php artisan make:filament-panel guru, lalu modifikasi provider sesuai snippet Section A.
  3. Generate widget kustom: php artisan make:filament-widget GuruOverview --panel=guru, lalu replace extends & isi method.
  4. Generate view: php artisan make:filament-widget GuruOverview --view → simpan di resources/views/filament/guru/widgets/guru-overview.blade.php.
  5. Generate 4 resource: php artisan make:filament-resource Question --generate --view --panel=guru (ulangi untuk Exam, Grade, Student). Set navigation properties sesuai Section B.
  6. Generate page Pengaturan: php artisan make:filament-page Settings --panel=guru.
  7. Tambahkan config/ai.php dengan key monthly_budget_idr.
  8. Build asset: npm run build untuk produksi, atau npm run dev untuk pengembangan lokal.
Opsional — butuh perubahan schema.
Widget GuruOverview menghitung "Biaya AI bulan ini" dari kolom questions.cost_cents. Kolom ini tidak ada dalam daftar data §5 brief — asumsinya adalah biaya dihitung dari sisi aplikasi AI provider dan dicatat saat soal disimpan. Bila kolom ini belum ada, ada tiga opsi:
  • Opsi A — tambah kolom. Migration: ALTER TABLE questions ADD COLUMN cost_cents INT UNSIGNED DEFAULT 0, ADD COLUMN is_ai_generated BOOLEAN DEFAULT FALSE. Isi dua kolom ini di QuestionGeneratorJob setelah pemanggilan API. (Disarankan — dipakai widget.)
  • Opsi B — hitung dari log. Tambahkan tabel ai_generation_logs (cost, model, prompt_hash, created_at) dan join. Lebih akurat tapi lebih banyak migration.
  • Opsi C — sembunyikan stat. Widget tampilkan 2 stat saja (antrian tinjauan + ujian akan datang) sampai ada schema. Tidak ideal karena kehilangan 1 dari 3 data point brief §4.
Tanpa salah satu dari ketiganya, stat "Biaya AI bulan ini" tidak bisa dihitung. Saya rekomendasikan Opsi A.

Yang tidak dilakukan di Tahap 4 (sesuai brief)

  • Tidak mendesain ulang komponen Form / Table / Section bawaan Filament.
  • Tidak membuat halaman Pengaturan baru (filosofi + field) — hanya daftarkan ke navigasi.
  • Tidak menyentuh Resource Question untuk layout list/detail — itu kerja Tahap 5 jika diminta.
  • Tidak membuat halaman login Filament (bawaan sudah cukup; hanya warna primary yang akan ter-override).
Tahap 4 selesai. Panel guru siap dipakai tanpa menulis ulang Filament. Dengan menambahkan satu kolom questions.cost_cents (atau Opsi B/C di atas), widget dasbor langsung menampilkan ketiga stat + antrian tinjauan. Brief §4 sudah terpenuhi: palet, navigasi, dan 1 widget dasbor.
