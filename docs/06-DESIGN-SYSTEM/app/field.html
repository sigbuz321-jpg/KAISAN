Field

Vertical stack of label → control (input/textarea/select) → helper / error message. Focus ring uses --accent.

States

default · focused · error · disabled · with prefix

HTML

<label class="k-field">
  <span class="k-field__label">Nama lengkap</span>
  <span class="k-field__control">
    <input class="k-field__input" type="text" placeholder="..." />
  </span>
  <span class="k-field__helper">Ditampilkan ke teman sekelas.</span>
</label>

<!-- error -->
<label class="k-field k-field--error">
  <span class="k-field__label">Nomor telepon</span>
  <span class="k-field__control">
    <input class="k-field__input" type="tel" />
  </span>
  <span class="k-field__helper">Nomor tidak valid. Minimal 10 digit.</span>
</label>
