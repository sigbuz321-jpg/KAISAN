Answer-option

The student-answer pill. Five states: default → selected → correct | wrong → locked after reveal.

States

default · selected · correct · wrong · locked

<button type="button" class="k-answer">
  <span class="k-answer__letter">A</span>
  <span class="k-answer__body">22</span>
  <span class="k-answer__trail"></span>
</button>

<button type="button" class="k-answer k-answer--selected">...</button>
<button type="button" class="k-answer k-answer--correct">...</button>
<button type="button" class="k-answer k-answer--wrong">...</button>
<button type="button" class="k-answer k-answer--locked" disabled>...</button>
Transition: default → selected on click. After "Kirim jawaban" the chosen row locks (k-answer--locked disabled) and the correct row reveals via k-answer--correct or k-answer--wrong.
