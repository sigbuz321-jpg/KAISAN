Button

Four variants across five states. Hit-target ≥40 px tall. Only one k-btn--primary per visual region.

Variants

default · hover · focus · disabled · processing

Sizes

md (default) · sm

Hover / focus preview

rendered statically · the actual hover and focus rings appear only when interacted with

HTML

<button type="button" class="k-btn k-btn--primary">Mulai Latihan</button>
<button type="button" class="k-btn k-btn--secondary">Lihat bank soal</button>
<button type="button" class="k-btn k-btn--ghost">Lewati</button>
<button type="button" class="k-btn k-btn--danger">Hapus sesi</button>

<!-- sm -->
<button type="button" class="k-btn k-btn--primary k-btn--sm">Simpan</button>

<!-- processing: pair disabled + k-btn--processing to lock double-submit -->
<button type="button" class="k-btn k-btn--primary k-btn--processing" disabled>Memuat…</button>
Anti-pattern: do not place two k-btn--primary buttons in the same visual region. Demote the second action to k-btn--ghost or k-btn--secondary.
