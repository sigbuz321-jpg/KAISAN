Tab-bar

Bottom navigation, 64 px tall, four tabs. Active tab uses --accent; inactive stays muted. Icons are stroke-based SVGs that inherit color from the parent.

Default — Latihan active

Other states

Ujian active · Peringkat active · Saya active

HTML

<nav class="k-tabbar">
  <button class="k-tab k-tab--active" type="button" aria-current="page">
    <span class="k-tab__icon" aria-hidden="true">
      <svg viewBox="0 0 24 24">
        <!-- book icon (Latihan) -->
        <path d="M5 5 H11 V20 H5 Z"/>
        <path d="M13 5 H19 V20 H13 Z"/>
        <path d="M5 5 V20"/>
        <path d="M13 5 V20"/>
      </svg>
    </span>
    Latihan
  </button>
  <!-- Ujian / Peringkat / Saya follow the same shape -->
</nav>
Only one tab carries k-tab--active at a time. Mirror the same value in aria-current="page" for assistive tech. Icons inherit color from the tab; currentColor on the SVG keeps state changes automatic.
