Banner

Full-width callout. Soft semantic fill with matching foreground and a leading SVG icon. Optional close action. Icons inherit color from the banner's semantic token.

Tones

info · success · warning · danger

Jaringan tidak stabil. Jawaban akan dikirim ulang otomatis.
Sesi telah tersimpan. Lanjut ke soal berikutnya.
Sesi berakhir dalam 5 menit.
Soal gagal dimuat. Periksa koneksi lalu coba lagi.

Without close action

default banner does not show a close button

Banners reserve one row above the fold on student screens. Do not stack more than one banner per screen — collapse lower-priority items into a list. The k-banner__close button inverts its icon stroke on hover by filling with the banner's current color.
