Question-card

Wraps a question body for the Ujian screen. Header row holds the level badge, a counter, and the timer; the prompt and option stack follow.

Default composition

level + counter + timer + prompt + 4 options

Berkembang Matematika Soal 3 dari 20 13:42
Berapa hasil dari 4x + 7 = 31?

Pilih satu jawaban. Tekan "Kirim" untuk mengunci pilihan.

After reveal (locked)

selected + correct row highlighted, others locked

Mahir Matematika Soal 3 / 20 13:18
Berapa hasil dari 4x + 7 = 31?

Jawaban benar: x = 6 → 4(6) + 7 = 31.
