KAISAN · Design System

Tahap 2 — Komponen Inti

15 komponen · Mobile-first 390 px · System stack · Tanpa CDN
Sentuh min. 44×44 px · Kontras WCAG AA

Keputusan baru yang dikunci di Tahap 2

Empat hal yang tidak ditentukan di Tahap 1 dan kini sudah diputuskan agar semua komponen konsisten.

1 · Warna per level kemampuan

Pemulabg-info · biru netral, baru mulai.
Berkembangbg-accent · amber hangat, di tengah jalan.
Mahirbg-success · hijau, pencapaian jelas.
Ahliamber gelap · master, finish.
Belum dimulaibg-neutral · abu-abu, tanpa penekanan.

Angka Elo tidak pernah dipakai sebagai warna. Tidak ada level "Expert" merah atau "Starter" hijau murahan.

2 · Mobile navigation (sebelumnya tidak ada)

Bottom tab bar 4 menu: Beranda, Latihan, Ujian, Peringkat. Di atasnya app bar dengan judul halaman dan ikon menu (akun/panel guru).

Pola ini mengikuti konvensi Android & iOS. Jempol di tengah layar bisa mencapai semua tab di layar 6". Hamburger di app-bar adalah escape hatch (akun, sign out, tautan ke panel guru).

3 · Indikator simpan otomatis (sebelumnya tidak ada)

Pill kecil di header kartu soal: Tersimpan · 13:42. Berubah jadi Menyimpan… selama 300–500 ms saat jawaban dikirim ke server.

Tanpa toast. Tanpa modal. Tanpa banner di tengah layar. Hanya satu pill kecil yang diam-diam mengkonfirmasi: "Kami dengar kamu, jawaban kamu aman."

4 · Blade components baru (Tahap 2)

Akan ditambahkan di resources/views/components/ui/: button, badge, badge-level, progress, banner, field (label + input + hint/error), answer-option, question-card, question-map, timer, tab-pill, list-card, save-indicator, leaderboard-row, app-header, tab-bar.

Blade component Filament (untuk panel guru) tidak disentuh. Hanya theme color yang di-override.

01 / Tombol

Tombol

resources/views/components/ui/button.blade.php

Empat varian tampilan (primer, sekunder, ghost, danger) × empat state (default, hover, disabled, processing). Sentuh minimum 44 px. Tekan: 1 px ke bawah, 150 ms.

Primer — aksi utama satu-satunya per layar

Sekunder — aksi pendukung

Danger — aksi yang tidak bisa dibatalkan

Dipakai hanya untuk "Kumpulkan ujian" dan "Keluar sesi". Tidak untuk batal/hapus biasa.

Penuh-lebar — default pada mobile 390 px

Tombol aksi utama di mobile selalu .btn-block (penuh 1 kolom).

Catatan implementasi 
// resources/views/components/ui/button.blade.php
@props([
  'variant' => 'primary',  // primary | secondary | ghost | danger
  'type' => 'button',
  'block' => false,
  'loading' => false,
  'disabled' => false,
])

<button
  type="{{ $type }}"
  {{ $attributes->class([
    'btn',
    'btn-' . $variant,
    'btn-block' => $block,
  ])->merge([
    'disabled' => $disabled || $loading,
    'aria-busy' => $loading ? 'true' : 'false',
  ]) }}
>
  {{ $slot }}
</button>

Di Livewire: gunakan wire:click untuk aksi utama. wire:target + wire:loading untuk memicu state memproses: 

<!-- Di Blade view -->
<x-ui.button
  variant="primary"
  block
  wire:click="submit"
  wire:loading.attr="disabled"
  wire:target="submit"
>
  <span wire:loading.remove wire:target="submit">Kumpulkan</span>
  <span wire:loading wire:target="submit" class="inline-flex items-center gap-2">
    Menyimpan…
  </span>
</x-ui.button>

04 / Bar progres

Bar progres

components/ui/progress.blade.php

Dua konteks: progres dalam level (0–100%) dan jumlah soal terhadap target sesi. Warna tidak berubah mengikuti level — konsisten dengan brand. Pertumbuhan visual cukup jadi motivasi.

Statis — saat halaman dimuat

Progres dalam level 42%
Soal sesi ini 7 / 10
Baru mulai 0%

Bergerak — berpindah setelah nilai jawaban

Hanya transition-[width] duration-300 ease-out — tidak ada animasi warna, tidak ada checkered pulse.

Progres dalam level 42% → 51%

+9% setelah menjawab benar.

Catatan implementasi 
// resources/views/components/ui/progress.blade.php
@props([
  'value' => 0,   // 0-100
  'label' => '',
  'caption' => '',  // mis. "7 / 10" atau "42%"
])

<div>
  @if ($label || $caption)
    <div class="flex items-baseline justify-between mb-1.5">
      <span class="text-sm font-medium">{{ $label }}</span>
      <span class="text-sm text-muted">{{ $caption }}</span>
    </div>
  @endif
  <div
    role="progressbar"
    aria-valuenow="{{ $value }}"
    aria-valuemin="0"
    aria-valuemax="100"
    aria-label="{{ $label }}"
    class="progress"
  >
    <div class="fill fill-accent" style="width: {{ $value }}%;"></div>
  </div>
</div>

Warna fill tunggal (fill-accent) untuk semua konteks progres. Tidak berganti warna mengikuti level: nuansa level sudah cukup di badge.

Catatan implementasi 
// resources/views/components/ui/question-card.blade.php
@props([
  'question',
  'state' => 'interactive',  // interactive|revealed|locked|preview
  'revealed' => false,  // guard kunci
  'preview' => false,   // mode guru
])

<div class="{{ $state === 'locked' ? 'qcard-locked' : 'qcard' }}">
  {!! $question->prompt_html !!}

  @foreach ($question->options as $opt)
    @php
      // revealed + preview → tampilkan kunci.
      // interactive → hanya 'selected'.
      // locked → semua tersembunyi.
      $state = match (true) {
        $state === 'locked' => 'locked',
        $preview                            => $opt->is_correct ? 'correct' : 'normal',
        $revealed                           => $opt->is_correct ? 'correct'
                                      : ($opt->id === $selected ? 'wrong' : 'normal'),
        default                             => $opt->id === $selected ? 'selected' : 'normal',
      };
    @endphp
    <x-ui.answer-option
      :letter="$opt->letter"
      :state="$state"
      :name="\"q-\".$question->id"
      wire:model="answers.{{ $question->id }}"
    >{{ $opt->text }}</x-ui.answer-option>
  @endforeach

  {{ $slot }}
</div>

Blade guard di Livewire: $revealed hanya true jika $this->exam->is_submitted && now()->gt($this->exam->closes_at). Atau $preview = auth()->user()->hasRole('guru') di view pratinjau.

Catatan implementasi 
// resources/views/components/ui/timer.blade.php
@props([
  'secondsRemaining',
  'threshold' => 60,  // detik, di bawah ini = urgent
])

@php
  $urgent = $secondsRemaining <= $threshold;
  $mm = str_pad(floor($secondsRemaining / 60), 2, '0', STR_PAD_LEFT);

  @endif

13 / Indikator simpan otomatis

Indikator simpan otomatis (BARU)

components/ui/save-indicator.blade.php

Masalah: murid tidak punya bukti jawaban tersimpan saat ujian. Solusi: pill kecil di header kartu soal yang diam-diam mengkonfirmasi. Dua state: tersimpan (default) dan menyimpan (300–500 ms saat transit). Tanpa toast, tanpa banner.

Tersimpan (default · 99% waktu)

Tersimpan · 13:42

Latar netral, border tipis, titik hijau. Teks selalu memuat jam agar murid tahu kapan terakhir disimpan (mis. setelah pergantian jawaban).

Menyimpan (300–500 ms · saat transit)

Menyimpan…

Latar info-soft, border info, titik info. Pulih ke "Tersimpan · [jam baru]" setelah server meng-ack. Tidak ada spinner — sesuai aturan animasi (transisi warna saja).

Posisi di kartu soal (mobile)

Soal 14 / 25 Tersimpan · 13:42

[Soal ujian aktif]

Catatan implementasi 
// resources/views/components/ui/save-indicator.blade.php
@props([
  'savedAt' => null',  // Carbon instance
  'state'  => 'saved',  // saved|saving
])

@php

@endphp

<span
  {{ $attributes->class([
